## Fixed extraction

Three independent standard fiducial realizations 0,1,2; five epochs in descending z (3,2,1,.5,0); 256^3 real-space CIC fields, 1000 h^-1 Mpc periodic box. Use same grid indices across epochs within each realization. Seed 20261126+ID, 4096 unique uniform grid indices without replacement per realization. No outcome-driven selection. Require finite cubic array and explicit density convention; zero-mean overdensity tolerance 1e-4 and lower bound -1.0001 (numerical tolerances, not clipping); count fields must be nonnegative with positive mean. Compute discrete periodic spherical mean using FFT of normalized grid-point top hat at 20 and 30 h^-1 Mpc. Remove numerical zero mode. Present smoothed trace-free tidal invariant sum_ij s_ij^2, Fourier multiplier k_i*k_j/k^2-delta_ij/3; mixed Nyquist modes zeroed for real-transform consistency. No CIC deconvolution. Coordinate values are index*grid spacing, not independently verified physical grid origin; confirm identical axis/origin conventions and simulation/phase identity with publisher metadata before interpreting.

Run from repository root in data-authorized environment:

    python notebooks/desi/quijote_history_extract.py /actual/path/3D_cubes/fiducial OUTPUT --convention overdensity

Use counts only if provider verifies count/mass-grid semantics. If files absent, list exact names and stop; do not substitute other cosmologies, different realization IDs, RSD fields or resolution without review. If equivalent legacy names, record mapping and stage aliases rather than silently change input identities. Prefer remote computation; no full particles requested. Deliver fiducial_0_histories.npz, fiducial_1_histories.npz, fiducial_2_histories.npz and manifest.json. Products carry indices, xyz, delta (4096,2,5), tidal_s2 (4096,2), redshifts/radii, and manifest includes per-file hashes, dtype, mean, byte count, source names and product hashes. ~1.6 MB total uncompressed arrays (plus metadata).
