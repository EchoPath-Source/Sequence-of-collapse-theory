# O-1 Observer Emergence — Original Roadmap Closure

**Status:** Original O-1A through O-1E roadmap complete at functional/operational level  
**Claim level:** Observer-like organization only; no consciousness claim  
**Date:** 2026-09-12

## 1. Original roadmap
The original O-1 program asked how a non-observing record-bearing pattern could become an observer-like pattern through:

`record -> persistence -> feedback -> adaptive feedback -> self-model -> recursive/metarepresentational access`.

The staged roadmap was:
- O-1A passive memory versus feedback;
- O-1B internal-state model;
- O-1C self-model ablation;
- O-1D recursive depth;
- O-1E conscious-access comparison.

This document closes that original ladder without promoting the results into a theory of consciousness.

## 2. O-1A — passive memory versus feedback
Completed. Persistent memory alone was insufficient. Memory became functionally observer-like only when it causally altered later sensing, action, or state transition.

Earned result:
`record persistence != causal reuse`.

## 3. O-1B — internal-state model
Completed. Self-state representations can improve action under decision-relevant conditions, but can also be neutral or harmful when the environment or policy does not make self-information useful.

Earned result:
`self-information != automatically useful self-information`.

## 4. O-1C — self-model ablation
Completed. Removing meaningful self-state channels can reduce performance where hidden self-dynamics determine rational action, but apparent self-model benefits disappear under some matched-information controls.

Earned result:
`self-model value must be demonstrated through ablation and causal controls`.

## 5. O-1D — recursive depth
Completed through the O-1D1–O-1D4 experiment families.

The program progressed through:
- self-state estimation;
- self-dynamics identification from autobiographical action-outcome history;
- policy selection from inferred hidden self-dynamics;
- calibrated uncertainty about the self-model;
- attempts at uncertainty-sensitive information gathering;
- value-of-information and causal-information gates;
- source-selection policies;
- world-context inference and changing-environment adaptation.

Key positive results:
1. Ordered autobiographical action-outcome history can identify hidden self-dynamics better than shuffled or donor history.
2. In balanced-regret environments, own autobiographical history can reduce held-out policy regret relative to shuffled, fixed, and mismatched-history controls.
3. Self-model reliability can be calibrated out of sample.
4. Selective probing can outperform indiscriminate probing in some regimes.
5. Coarse environment context can be inferred from experience and updated after distribution change.

Key negative results:
1. Better self-model accuracy does not guarantee better policy value.
2. Confidence does not equal value of information.
3. Additional recursive/metacognitive depth often adds representation without robustly improving control.
4. Empirical and causal information policies can be unstable across training samples.
5. Internal physical location has no special status when information, timing, computation, and action authority are matched.
6. Repeated positive-looking effects disappear under stronger provenance, policy-stability, or carryover controls.

Therefore O-1D does not reveal a sharp observerhood phase transition. It instead supports a graded architecture in which additional recursive depth creates separable functional capacities whose value depends on task structure.

## 6. O-1E — conscious-access comparison
Completed only as a comparison of candidate functional correlates associated with conscious-access theories. It is not a test for phenomenology.

### O-1E1 global access
Global availability improved integration of distributed evidence in a task that required multi-source information pooling.

Result:
- local-access accuracy: 0.78683
- global-access accuracy: 0.91700
- paired gain: +0.13017, 95% CI [0.12758, 0.13276]

Interpretation:
`global accessibility can be functionally useful when distributed evidence must be integrated`.

### O-1E2 recurrence equivalence
Sequential recurrent accumulation and batch feedforward integration produced identical predictions when both received identical evidence and computed the same sufficient statistic.

Result:
- recurrent accuracy: 0.96178
- batch accuracy: 0.96178
- prediction disagreement: 0

Interpretation:
`temporal integration matters; recurrence itself is not uniquely privileged`.

### O-1E3 metarepresentational access
Explicit access to first-order reliability improved downstream reporting of whether the first-order decision was likely correct without changing first-order classification performance.

Result:
- first-order accuracy: 0.89137
- no-meta correctness-report balanced accuracy: 0.50000
- explicit-meta balanced accuracy: 0.77916

Interpretation:
`task performance and access to a representation of task reliability are distinct functional capacities`.

## 7. Final operational hierarchy
The original O-1 program supports the following graded ladder:

`record`
`-> persistence`
`-> causal reuse`
`-> adaptive feedback`
`-> self-state model`
`-> autobiographical self-dynamics model`
`-> calibrated model reliability`
`-> world-context model`
`-> metarepresentational/global access`

These capacities are measurable and separable.

No single rung is shown to be necessary or sufficient for consciousness.

## 8. Final O-1 conclusion
The strongest defensible result is:

> Observer-like organization can be operationalized as persistent records entering closed causal loops that alter future information acquisition, regulation, self-modeling, and access to internal representations.

The program does **not** establish:
- phenomenal consciousness;
- sentience;
- subjective experience;
- a privileged internal spatial location;
- a novel physical observer force;
- a consciousness-triggered collapse law.

The original O-1 roadmap is therefore complete as a functional observer-emergence program.

Any future consciousness work should begin as a new program with independent hypotheses and discriminators rather than extending O-1 by relabeling observer-like function as consciousness.

## 9. Engineering handoff
The completed O-1 results can now inform physics-independent engineering branches such as Synthetic History Architecture, Event-History Neural Networks, EchoNet telemetry, and EchoForms persistent-agent identity tests. Those branches should inherit O-1's controls:

- own-history vs shuffled-history;
- donor and stale-history controls;
- matched information/computation budgets;
- self-model ablations;
- policy-stability checks;
- internal vs matched external controller tests;
- explicit distinction between representation and causal utility.
