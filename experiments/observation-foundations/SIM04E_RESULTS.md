# SIM-04E — SoCT Memory Injection / Cross-Protocol Gate Results

**Status:** first SoCT-specific synthetic injection benchmark complete  
**Claim level:** mathematical/identifiability viability only; this is **not evidence that a physical SoCT memory field exists**.

## Question

Does the canonical SoCT phenomenological memory equation define a transferable intervention signature that can be distinguished, in a controlled synthetic setting, from simpler instantaneous-medium and ordinary local-memory alternatives?

The injected field is the discrete graph version of

```math
partial_t M = alpha C - beta M + D_M nabla^2 M.
```

Only one feedback channel is allowed:

> `M` produces a small fractional propagation-delay residual on an edge through the average memory field at the edge's two endpoints.

No topology change, susceptibility change, or second free feedback channel is provided.

## Simulation design

An `8 x 8` spatial graph is used. Four collapse/source histories are defined:

```text
A, B -> parameter fitting / training histories
C, D -> held-out histories
```

The candidate models are:

1. **instantaneous** — response proportional only to current source `C(t)`;
2. **spatial instantaneous** — current source can spread spatially, but carries no temporal memory;
3. **local memory** — source + decay memory with `D_M = 0`;
4. **diffusive memory** — source + decay + diffusion.

For every candidate, one overall feedback scale is fit on protocols `A` and `B`. Memory parameters are selected on the same training histories and then frozen before protocols `C` and `D` are scored.

The synthetic SoCT-like generator uses

```text
beta_true = 0.08
D_true    = 0.18
scale     = 0.05
noise sigma per edge/time sample = 0.002
```

Twelve independent noise seeds are evaluated.

## Main held-out result

Mean test RMSE on held-out protocols `C` and `D`:

| Data generator | Instantaneous | Spatial instantaneous | Local memory | Diffusive memory | Fitted diffusive `(beta, D)` |
|---|---:|---:|---:|---:|---:|
| **diffusive / SoCT-like** | 0.00736 | 0.00724 | 0.00443 | **0.00200** | **(0.080, 0.180)** |
| local memory | 0.01175 | 0.01176 | **0.00200** | **0.00200** | **(0.100, 0.000)** |
| spatial instantaneous | 0.00212 | **0.00200** | 0.00217 | 0.00211 | (0.180, 0.300) |
| instantaneous | **0.00200** | 0.00200 | 0.00233 | 0.00234 | (0.180, 0.153) |

The noise floor is approximately `0.002`.

## Interpretation

### 1. The SoCT equation defines a transferable synthetic signature

When the data are actually generated by the source-decay-diffusion equation, the fitted diffusive model reaches the measurement-noise floor on unseen source histories:

```text
diffusive test RMSE ~ 0.00200
local-memory RMSE   ~ 0.00443
instantaneous RMSE  ~ 0.00736
```

The fitted parameters return

```text
beta = 0.08
D_M  = 0.18
```

for every tested noise seed at the present grid resolution.

This demonstrates a narrow viability claim:

> the canonical SoCT memory equation can generate a cross-protocol signature that is not automatically absorbed by the tested instantaneous or no-diffusion nulls.

It does **not** show that nature contains such a field.

### 2. Diffusion is not automatically manufactured when the true process is local memory

When data are generated by ordinary local memory,

```text
beta_true = 0.10
D_true    = 0
```

the larger diffusive model fits

```text
beta = 0.10
D_M  = 0.00.
```

Its RMSE is identical to the local-memory model because local memory is the `D_M = 0` nested limit of the larger equation.

This is an important null result:

```text
if fitted D_M -> 0,
the simpler local-memory interpretation should be preferred.
```

A fit of the general SoCT equation is not by itself evidence for a propagating memory field.

### 3. Instantaneous spatial spreading does not reproduce temporal memory on held-out histories

When the true generator has spatial smoothing but no temporal persistence, the correct spatial-instantaneous model reaches the noise floor:

```text
RMSE ~ 0.00200.
```

The diffusive-memory model is slightly worse (`~0.00211`) and is pushed to the high edge of the exploratory `(beta, D)` grid.

That boundary-seeking behavior is a warning sign rather than positive evidence for memory.

### 4. A purely instantaneous generator is also not falsely selected as memory

For instantaneous data the instantaneous model remains at the noise floor, while local and diffusive memory are worse.

The diffusive fit again moves toward a fast-decay boundary rather than recovering a stable nonzero memory law.

## Matched-present / different-history test

A separate protocol pair is constructed so that from `t = 40` onward both systems have the **same current source condition**, but one system experienced an earlier localized source pulse and the other did not.

For the diffusive generator, at `t = 40` the predicted edge-delay residual caused solely by prior history has

```text
edge-wise RMS residual = 0.00272
per-edge noise sigma   = 0.00200
RMS / noise            = 1.36
```

The instantaneous model predicts exactly zero history residual.

A representative no-diffusion local-memory fit retains some historical signal but gives only about

```text
correlation ~ 0.53
```

with the spatial shape of the true diffusive residual at that time.

Per-edge SNR is modest, but the residual is distributed over many edges, so a field-wide predeclared statistic can gain substantial aggregate power. A future empirical design would need to account for correlated noise rather than assuming all edges are independent.

## What SIM-04E establishes

It establishes only that the present SoCT equation is **mathematically distinguishable in a favorable controlled environment** when its diffusion and relaxation structure are genuinely present.

The useful surviving chain is

```text
specified source history C
    -> M through fixed alpha/beta/D_M dynamics
    -> one predeclared causal observable
    -> held-out history prediction.
```

This is stronger than fitting an arbitrary history-dependent residual after the fact.

## What SIM-04E does not establish

It does not show:

- that collapse events create a new physical field;
- that the proposed `C(x,t)` source is the correct quantum quantity;
- that propagation-delay residuals are the real coupling channel `O_M`;
- that the fitted memory variable cannot ultimately be represented as ordinary hidden environmental state;
- that effective causal-geometry change implies a change in fundamental spacetime geometry;
- that the chosen values of `alpha`, `beta`, `D_M`, or feedback scale are physically realistic.

The synthetic generator is the same model that is later recovered. Parameter recovery therefore validates the inference pipeline, not the theory's truth.

## Strongest lesson from SIM-04D + SIM-04E

The pair of simulations gives the appropriate burden of proof for SoCT memory:

```text
history dependence alone is insufficient;
geometry distortion alone is insufficient;
a generic memory fit is insufficient.
```

A persuasive SoCT-specific result would instead require all of the following in real or independently simulated physics:

```text
predeclared collapse-derived source C
nonzero transferable relaxation beta
nonzero transferable spatial term D_M
fixed feedback law lambda_M
matched-present / different-history residual
held-out protocol prediction
failure of simpler environmental-memory and medium-change nulls
```
