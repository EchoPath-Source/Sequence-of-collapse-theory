# SoCT Memory Field — Current Necessity / Novelty Status

**Status:** research assessment after SIM-02 through SIM-04I  
**Claim level:** internal scientific positioning; not empirical confirmation or refutation  
**Purpose:** prevent synthetic viability results from being misread as evidence that a physical memory field is already required.

## Bottom line

The current simulation program does **not** show that an SoCT memory field `M` is necessary to explain known quantum measurement or record-formation behavior.

The conservative conclusion is:

> **Standard quantum/open-system dynamics already explain interaction, entanglement, decoherence, record persistence, record erasure, redundancy, and ordinary environmental memory. The proposed `M` field remains a mathematically viable additional-state hypothesis, but it has not yet been shown to be empirically required or uniquely identifiable.**

This is not a failure of the program. It defines the burden of proof clearly.

---

## What has been established

### 1. The memory equation is mathematically viable

The phenomenological equation

```math
partial_t M = alpha C - beta M + D_M nabla^2 M
```

is stable in the tested toy systems and creates specific relaxation, spatial-spreading, and matched-present/different-history signatures.

When synthetic data are generated by this equation, its parameters can be recovered on held-out source histories.

This establishes **synthetic identifiability under favorable assumptions**, not physical existence.

### 2. The model is falsifiable against nested nulls

The larger diffusive model does not always win.

When the true generator contains only local memory, the fit collapses to

```text
D_M = 0
```

and the simpler local-memory model should be preferred.

When the true generator is instantaneous, instantaneous models remain preferred.

When exact-reset H0 data are generated, the H2 coupling is driven toward zero and the complexity penalty favors H0.

### 3. A complete ordinary quantum model already explains much of the observation hierarchy

Explicit unitary simulations demonstrate, without `M`, that

```text
peak decoherence != persistent record formation
record persistence != record redundancy
transient environmental information != retained environmental information.
```

Thus the standalone operational observation model may be useful without implying any new physical field.

### 4. An extra state can create a post-reset prediction

If an additional state survives after all explicitly modeled ordinary degrees of freedom are reset, a fresh probe can retain history dependence.

This is a valid H2 signature in simulation.

But the signature only becomes evidence for new physics if conventional state completions are independently excluded.

## What has *not* been established

The current simulations do not establish that:

```text

M produces any already-observed anomaly;
M is the unique explanation of a post-reset residual;
M modifies fundamental spacetime geometry;
Gamma_rec is the unique observation-source functional;
consciousness is required for lower-level observation.
```

## Why ordinary hidden state remains the main competitor

SIM-02 showed the general state-completion problem:

```text
history dependence
    -> incomplete present-state description
```

but not

```text
history dependence
    -> unique memory-field ontology.
```

SIM-04D and SIM-04H then constructed exact equivalences between a named memory state and an ordinary hidden state with the same dynamics.

SIM-04I strengthens that result:

> A conventional residual reservoir given the same source, decay, diffusion, and probe coupling as `M` is indistinguishable from `M` using probe-only data.

Independent reset diagnostics can break the degeneracy only if they actually couple to the conventional hidden mode with sufficient sensitivity.

A completely diagnostic-blind conventional reservoir remains structurally non-identifiable.

## Does `M` currently provide novel predictions?

### In synthetic model space: yes

Once `M` is added, it predicts a specific combination of

```text
post-source persistence
spatial spreading
matched-present / different-history residual
wait-time dependence
cross-protocol parameter transfer
fresh-probe residual after ordinary reset.
```

Those are genuine model predictions.

### Relative to complete conventional physics: not yet uniquely

An arbitrary conventional hidden reservoir can be assigned the same phenomenological dynamics.

Therefore these predictions are not yet uniquely diagnostic of the **origin** or **ontology** of `M`.

The next novelty target is not another fit of the same equation. It is a constraint that follows from the proposed SoCT origin of `M` and is difficult or impossible for an arbitrary conventional reservoir to reproduce without additional structure.

Potential targets include:

```text
source-law constraints tied specifically to record production;
parameter relations fixed by the underlying SoCT Hamiltonian;
backreaction / conservation constraints;
cross-observable coupling relations;
universal scaling relations across physically different implementations.
```
