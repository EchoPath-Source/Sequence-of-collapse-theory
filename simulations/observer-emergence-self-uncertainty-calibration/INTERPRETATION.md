# O-1D4b — Held-Out Metacognitive Calibration

A 12,000-history evaluation set, independent of O-1D4a calibration, tested whether empirical confidence predicts actual self-model correctness.

Overall hidden-regime classification accuracy was `0.92625`. Expected calibration error across the predeclared confidence bins was approximately `0.00307`.

Examples:
- confidence ~0.635 -> held-out accuracy ~0.655;
- confidence ~0.770 -> accuracy ~0.764;
- confidence ~0.890 -> accuracy ~0.892;
- confidence ~0.958 -> accuracy ~0.958;
- confidence ~0.990 -> accuracy ~0.991.

Thus:

`estimated confidence in the self-model predicts actual probability that the self-model is correct.`

This earns a limited functional metacognitive rung: a second-order variable about reliability of self-inference can be calibrated out of sample.

It does **not** establish subjective confidence, awareness of uncertainty, consciousness, or intrinsic agency. The confidence map is ordinary empirical uncertainty estimation.

The next test asks whether this calibrated uncertainty has causal value: when confidence is low, can gathering additional self-information improve later decisions enough to justify its cost?
