# SIM-04H — H0/H1/H2 Complete Reset-and-Probe Results

**Status:** first complete-reset nested-hypothesis benchmark complete  
**Claim level:** synthetic methodology/identifiability result only; this is **not empirical evidence for an SoCT memory field**.

## Central question

> **Does an additional physical state `M` add a testable post-reset prediction beyond a complete ordinary quantum record model?**

SIM-04H makes the nested hypotheses explicit.

### H0 — complete ordinary quantum record model

The modeled system, detector, and environment fragments evolve unitarily during the record-producing history. After the history, all modeled ordinary quantum degrees of freedom are reset exactly to the same reference state before a fresh probe is introduced.

Under H0, once that complete reset has occurred, prior record history cannot affect the fresh probe through any of the modeled ordinary degrees of freedom.

### H1 — operational record summary, no additional physical state

H1 keeps the operational observation/record-production description (`Gamma_rec`, retained-record score, redundancy, persistence, etc.) as a useful summary of the ordinary quantum history, but adds no new dynamical state.

Therefore in the post-reset experiment:

```text
H1 and H0 make the same physical prediction.
```

The reset-and-probe protocol can test `H2` against `{H0,H1}`, but it cannot distinguish H0 from H1 because H1 is descriptive rather than new physics.

### H2 — ordinary quantum record model plus `M`

H2 adds an additional state sourced by retained record production:

```math
partial_t M = alpha C_obs - beta M + D_M nabla^2 M.
```

The ordinary S/D/E reset does not reset `M`. A fresh probe receives one predeclared phase coupling

```math
phi = lambda_M M,
```

and is read out in the `Y` basis.

## Standard quantum source stage

Each record-producing event is generated by the same explicit five-qubit unitary model used in SIM-04G:

```text
S  = observed qubit
D  = detector
E1,E2,E3 = environment fragments.
```

The history sequence is

```text
partial S-D measurement
-> zero/one/three D->E record copies
-> optional erasure of those copies
-> local S-D unmeasurement.
```

A retained-record source score is then calculated entirely within ordinary quantum mechanics:

```math
C_obs(event) proportional sum_k I(S:E_k)
```

after the local unmeasurement.

If the environment copies are erased before unmeasurement, the retained-record score returns to numerical zero.

These source events are placed at different sites and times on a seven-site chain. Protocols `A` and `B` are used for parameter fitting; `C` and `D` are held out. Protocol `D` contains a strong but erased record event as a persistence adversary.

After the source history, **all modeled ordinary quantum degrees of freedom are reset exactly**. Only H2 retains the additional `M` state.

Fresh probes are then applied at all seven sites after waits of

```text
0, 3, 7, 12
```

time steps.

Each probe point uses `12,000` simulated `Y`-basis shots, giving a zero-signal sampling scale of roughly

```text
1 / sqrt(12000) ~ 0.0091.
```

## Part A — H2-generated synthetic data

The planted H2 parameters are

```text
beta_true   = 0.08
D_M_true    = 0.15
lambda_true = 3.00.
```

Across 24 independent shot-noise realizations, mean held-out performance is:

| Model | Held-out RMSE |
|---|---:|
| H0 / H1 reset prediction | 0.20296 |
| ordinary local reservoir (`D=0`) | 0.16569 |
| **H2 diffusive memory** | **0.00890** |

The H2 result is at the expected shot-noise scale.

Mean recovered H2 parameters are

```text
beta   = 0.080
D_M    = 0.150
lambda = 3.000
```

with only small shot-noise variation in the fitted coupling.

The mean BIC difference is

```text
Delta BIC = BIC(H2) - BIC(H0) ~ -370.0
```

and

```text
BIC(H2) - BIC(local reservoir) ~ -351.2.
```

Negative values strongly favor H2 **for data that were deliberately generated by H2**.

### Interpretation

This is a synthetic validation of the reset signature:

```text
retained ordinary quantum records
    -> C_obs
    -> M
    -> exact ordinary reset
    -> wait / spatial spread
    -> fresh-probe residual.
```

It shows that the proposed extra state can produce a held-out signal that a fully reset H0/H1 model does not contain.

It does **not** show that nature contains `M`.

## Part B — exact-reset H0-generated data

The same fitting pipeline is applied to data generated with no post-reset memory state.

Mean held-out results:

| Model | Held-out RMSE |
|---|---:|
| **H0 / H1** | **0.00901** |
| local reservoir | 0.00908 |
| H2 | 0.00908 |

The H2 fit is driven toward essentially zero coupling:

```text
mean fitted lambda ~ 0.023.
```

Its other parameters become weakly determined because a nearly zero coupling makes them physically irrelevant.

The mean complexity penalty is

```text
BIC(H2) - BIC(H0) ~ +10.9,
```

so the simpler exact-reset model is preferred.

### Interpretation

The inference pipeline does not mechanically demand a nonzero `M` when the post-reset data are ordinary shot noise.

This is an important null check.

---

## Part C — ordinary local-reservoir null

A conventional unreset local state is then used as the data generator. It is sourced by the same ordinary record history and decays in time, but it has

```text
D = 0.
```

Mean held-out results:

| Model | Held-out RMSE |
|---|---:|
| H0 / H1 | 0.32313 |
| **ordinary local reservoir** | **0.00857** |
| H2 | 0.00857 |

The larger H2 model recovers

```text
beta = 0.080
D_M  = 0.000
lambda = 3.000.
```

Thus it collapses to the local-reservoir nested limit.

The mean comparison

```text
BIC(H2) - BIC(local reservoir) ~ +4.03
```

favors the simpler conventional local-memory explanation.

### Interpretation

A post-reset history residual is **not automatically evidence for a propagating SoCT field**.

If the fitted diffusion term collapses to zero and an ordinary local reservoir explains the data, the conventional explanation should be preferred.

## Exact H0/H1 equivalence in this protocol

The maximum post-reset prediction difference between H0 and H1 is

```text
0.0.
```

This is conceptual, not numerical accident.

H1 summarizes ordinary record formation but adds no independent physical state. After a truly complete ordinary reset, it has no channel through which past records can affect a fresh probe.

Therefore:

```text
reset-and-probe tests new physical persistence,
not the usefulness of the operational observation summary itself.
```

## Fundamental ontology boundary

SIM-04H also includes an exact counterexample.

Suppose a conventional hidden field/reservoir is assigned exactly the same

```text
source law
beta
spatial diffusion
probe coupling
```

as the proposed `M` field.

Then the restricted reset-and-probe observations are identical:

```text
max absolute prediction difference = 0.0.
```

So even a successful real reset-and-probe residual would establish at most:

> the explicitly modeled ordinary state description is incomplete and an additional persistent degree of freedom is useful.

It would **not by itself establish the ontology or name of that degree of freedom**.

This is the same identifiability lesson found in SIM-02 and SIM-04D, now applied directly to the central H0/H1/H2 test.

## What SIM-04H establishes

The simulation establishes four narrow results:

1. a fully reset ordinary quantum record model predicts no post-reset history residual;
2. an additional source-decay-diffusion state can generate a transferable post-reset residual after the ordinary modeled state is matched;
3. the pipeline does not select that state when exact-reset H0 data are generated;
4. when a simpler local reservoir generates the residual, the general H2 model collapses to `D_M = 0` and the simpler null is preferred.

The central viable signature is therefore

```text
matched ordinary quantum state
+ different retained-record histories
+ fixed waiting-time/spatial residual law
+ held-out prediction
```

rather than generic hysteresis or generic decoherence.

---

## What SIM-04H does not establish

It does not show that:

- a real laboratory can reset every relevant ordinary environment degree of freedom;
- an observed residual could not arise from an unmodeled conventional reservoir;
- the chosen `sum I(S:E_k)` source is the unique observation functional;
- the proposed `M` state is fundamental rather than emergent;
- the probe-phase channel is the physical `O_M` coupling;
- SoCT is empirically correct.

The most difficult empirical requirement is therefore **reset completeness / environmental closure**.

A credible experiment must independently bound residual ordinary environmental state strongly enough that a post-reset signal cannot simply be assigned to uncontrolled standard physics.
