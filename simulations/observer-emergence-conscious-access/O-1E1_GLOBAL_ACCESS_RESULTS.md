# O-1E1 — Global Access Comparison

## Purpose
Test a functional correlate often associated with conscious-access theories: whether making distributed records globally available improves downstream integration. This is not a consciousness test.

## Design
A latent binary state generates three independent noisy cues. A downstream query is randomly assigned to one of three modules. The local-access control receives only that module's cue. The global-access condition receives the pooled evidence from all three cues. The task is to recover the latent state.

N = 100,000 held-out episodes. Noise SD = 1.25. No learning or post-hoc tuning is performed on the held-out set.

## Frozen results
- local-access accuracy: 0.78683
- global-access accuracy: 0.91700
- paired improvement: +0.13017
- 95% CI: [0.12758, 0.13276]

## Interpretation
Global availability is functionally useful when the task genuinely requires integration of distributed evidence. This supports global accessibility as an operational variable in observer-like organization.

It does not show that global broadcast is necessary or sufficient for consciousness. The gain is attributable to information integration/access, not phenomenology.
