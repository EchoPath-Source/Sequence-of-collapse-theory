# SIM-04F — Observation-Derived Memory Source Results

**Status:** first operational source-integration benchmark complete  
**Claim level:** synthetic mathematical viability only; this is **not evidence that observation or record formation creates a new physical field in nature**.

## Question

Can the memory source `C_obs` be derived from the operational observation model rather than supplied as arbitrary pulses, and can the resulting source law transfer to unseen interaction/record protocols under the same downstream SoCT memory dynamics?

The tested chain is

```text
interaction theta
    -> conditional pointer states
    -> trace-distance distinguishability
    -> accessible binary information
    -> ordinary record acquisition / persistence
    -> candidate C_obs source
    -> dM/dt = alpha C_obs - beta M + D_M Laplacian(M)
    -> one propagation-delay residual.
```

This simulation intentionally separates the ordinary detector record state `R` from the proposed SoCT memory state `M`.

## Pointer / information model

Conditional pointer states are

```math
|o_0> = |0>,
```

```math
|o_1> = cos(theta)|0> + sin(theta)|1>.
```

Their trace distance is

```math
D_tr = |sin(theta)|.
```

For equal prior probabilities, the Helstrom error is

```math
P_e = (1-D_tr)/2,
```

and the operational accessible-information proxy is

```math
I_acc = 1-H_2(P_e).
```

An ordinary record state is updated through

```math
Delta R_t^+ = a I_acc(t) [1-R_{t-1}],
```

```math
R_t = (1-e_t)R_{t-1} + Delta R_t^+.
```

The persistence-aware source candidate is

```math
Gamma_rec(t)
= Delta R_t^+ [1-e_t]^H A_d(t).
```

## Competing source mappings

Every candidate receives the **same** source-decay-diffusion memory model and may fit the same downstream parameters `(beta, D_M, scale)` on training protocols `A` and `B`.

The candidates are

```text
interaction  = normalized theta
info         = I_acc
omega        = I_c * D_tr * R * A_d
gamma_acq    = Delta R^+ * A_d
gamma_rec    = Delta R^+ * persistence * A_d.
```

Protocols `C` and `D` are held out.

Protocol `D` is deliberately adversarial: it has **strong interaction but highly fragile records**. A source that equates interaction or information with durable record production should overpredict the memory signal there.

## Synthetic generator

The primary synthetic data generator uses

```text
source      = Gamma_rec
beta_true   = 0.08
D_M_true    = 0.18
feedback scale = 0.05
noise sigma = 0.0015 per edge/time sample.
```

Twelve independent noise seeds are evaluated.

## Primary held-out result

Mean held-out RMSE:

| Source model | All held-out | Protocol C | Fragile-record D | Mean fitted beta | Mean fitted D_M |
|---|---:|---:|---:|---:|---:|
| interaction | 0.001707 | 0.001561 | 0.001841 | 0.179 | 0.300 |
| info | 0.001723 | 0.001575 | 0.001859 | 0.180 | 0.300 |
| omega | 0.001601 | 0.001627 | 0.001574 | 0.180 | 0.300 |
| gamma_acq | 0.002456 | 0.001496 | 0.003135 | 0.080 | 0.177 |
| **gamma_rec** | **0.001497** | **0.001495** | **0.001500** | **0.080** | **0.177** |

The measurement-noise floor is approximately

```text
0.0015.
```

For `gamma_rec`, the correct diffusion grid point

```text
D_M = 0.18
```

is selected in 10 of 12 noise realizations; the remaining two select the neighboring grid value `0.16`. `beta = 0.08` is selected in all 12 runs. The mean fitted scale is approximately `0.0495` for a planted value of `0.05`.

## Interpretation

### 1. The observation model can supply the memory source without hand-written `C(t)` pulses

The main viability result is the completed synthetic bridge

```text
theta
 -> D_tr
 -> I_acc
 -> record acquisition / persistence
 -> Gamma_rec
 -> M
 -> held-out causal residual.
```

When data are generated by that chain, the same source mapping and memory parameters learned on `A/B` transfer to `C/D` at the noise floor.

This closes the specific mathematical gap left by SIM-04E, where `C` was injected directly.

### 2. Persistence matters strongly in the fragile-record adversary

`gamma_acq` omits the persistence factor. It performs essentially at the noise floor on ordinary held-out protocol `C`:

```text
C RMSE ~ 0.001496,
```

but fails badly on the fragile-record protocol:

```text
D RMSE ~ 0.003135.
```

By contrast

```text
gamma_rec D RMSE ~ 0.001500.
```

So the benchmark successfully distinguishes

```text
information acquisition
```

from

```text
robust record production.
```

### 3. Raw interaction and information partly compensate by distorting memory parameters

The `interaction`, `info`, and `omega` source models remain moderately predictive, but their best fits push the downstream memory parameters to the upper exploratory boundaries:

```text
beta ~ 0.18
D_M ~ 0.30.
```

That boundary-seeking behavior is a diagnostic warning: an incorrect source law can partly mimic the correct output by forcing the memory dynamics into an artificially fast-decay / high-spread regime.

Therefore source-law and memory-law inference cannot safely be performed independently.

### 4. `Omega` remains a serious competing source

The factorized `omega` source achieves

```text
held-out RMSE ~ 0.001601,
```

which is worse than the planted `gamma_rec` source but still close to the `0.0015` noise floor.

Therefore SIM-04F does **not** uniquely establish `Gamma_rec` as the correct physical observation functional.

The stronger conclusion is only:

> record-aware source constructions can be distinguished from raw interaction/information under adversarial persistence conditions, and the specific planted `Gamma_rec` law is recoverable in this controlled benchmark.

A later quantum/open-system benchmark should compare `Omega`, `Gamma_rec`, decoherence rate, environmental redundancy, and reversible correlation directly.

## Generator sanity checks

To make sure the fitting pipeline does not mechanically prefer `Gamma_rec`, separate synthetic datasets were generated from other source laws and fit with the same candidate library.

| True source generator | Best recovered source | Best held-out RMSE | Runner-up RMSE |
|---|---|---:|---:|
| gamma_rec | gamma_rec | 0.001504 | 0.001607 |
| gamma_acq | gamma_acq | 0.001504 | 0.002166 |
| omega | omega | 0.001504 | 0.003029 |
| info | info | 0.001504 | 0.001616 |

Thus the pipeline does not automatically select the persistence-aware model when a different source law generated the data.

## The source-memory confound

`R_t` is an ordinary physical record variable, and it is already history dependent.

Therefore the chain contains two conceptually different forms of memory:

```text
ordinary detector/environment record R
    -> observation-derived source C_obs
    -> proposed SoCT field M.
```

History dependence in `C_obs` cannot be counted as evidence for `M`.

A future empirical or higher-fidelity simulation must independently measure/reset the ordinary record state and ask whether a residual attributed to `M` survives with the predeclared `beta`, `D_M`, and feedback law.

## What SIM-04F establishes

It establishes only a synthetic derivational viability claim:

> the repo's operational observation model can be instantiated as a concrete binary pointer/record process, used to derive a persistence-aware `C_obs`, and connected to the canonical SoCT memory equation with transferable held-out predictions.

## What SIM-04F does not establish

It does not show that

- real quantum observation creates `C_obs` in this form;
- `Gamma_rec` is unique or fundamental;
- ordinary decoherence / environment records require a new memory field;
- record persistence physically sources spacetime or gravity;
- the binary pointer model is an adequate model of general measurement;
- consciousness is involved;
- the SoCT field `M` exists in nature.

## Next gate

The highest-value next step is to replace the analytic binary pointer proxy with an explicit **qubit + detector + environment open-system simulation**.

That benchmark should independently vary

```text
measurement interaction strength
pointer distinguishability
environmental decoherence
record persistence / erasure
reversible correlation / recoherence
redundant environmental records.
```

The goal is to determine whether `Gamma_rec` or `Omega` tracks a genuinely distinct operational property, or merely re-parameterizes standard decoherence / information flow.
