# SoCT Observer-Emergence Crossfeed Map

**Status:** Active adjacent research map  
**Purpose:** Define how O-1 observer-emergence research can inform the lower operational-observation/history-memory track without contaminating it with consciousness assumptions.

## Two-track architecture

### Track 1 — Physical observation / history memory

```text
interaction
-> distinguishable record
-> persistence/redundancy/recoverability
-> Gamma_rec
-> candidate memory M
-> history-dependent physical discriminator
```

This track is directly tied to SOC-HISTORY-01.

### Track 2 — Observer emergence / first tuning fork

```text
record
-> persistent internal state
-> feedback
-> adaptive sensing/action
-> recursive self-model
-> observer-like organization
```

This track does not assume consciousness.

## How Track 2 can inform Track 1

### 1. Record relevance may depend on causal reuse

Track 1 currently treats durable record production as a candidate source using persistence, accessible information, redundancy, and recoverability.

O-1 adds a new possible discriminator:

```text
Does the stored record causally alter later information acquisition or state transition?
```

This suggests a future source refinement in which record production and record *reuse* are kept separate:

```math
Gamma_rec = record-production rate
Gamma_use = causal rate at which stored records alter future interaction
```

Track 1 should not automatically replace `Gamma_rec` with `Gamma_use`, but O-1 can test whether causal reuse identifies a physically meaningful subclass of records.

### 2. Persistence can be made functional rather than purely temporal

A record that persists but never changes anything may be physically different, for observer-emergence purposes, from a record that is repeatedly consulted.

O-1 can therefore distinguish:

```text
passive persistence
vs
causally active persistence
```

This may help Track 1 decide whether the memory source should depend only on durability or on later causal accessibility.

### 3. O-1 can generate better sham histories

If adaptive observer-like systems repeatedly read and rewrite their own memory, O-1 can define history protocols with the same raw number of record events but different feedback topology.

For example:

```text
A: record created, stored, never reused
B: same record burden, repeatedly reused in feedback
```

If Track 1 ever observed a difference between A and B after ordinary-state matching, that would discriminate simple record-counting models from feedback-sensitive memory models.

### 4. O-1 can define dose axes beyond event count

Candidate orthogonal dose variables include:

```text
record persistence
record redundancy
feedback strength
reuse count
self-model depth
causal influence on future sensing
```

These may become future experimental dose families, but only after the basic SOC-HISTORY-01 record-history effect is tested.

### 5. O-1 may expose hidden confounds for Track 1

Adaptive feedback changes control burden, timing, energy use, sampling pattern, and internal state distribution. Those are precisely the kinds of ordinary carryover variables Simulations 4d-4f showed can generate false history effects.

Therefore O-1 is useful not only for generating hypotheses but also for discovering new nuisance channels that Track 1 must control.

## What must NOT flow from Track 2 into Track 1

Do not infer:

```text
observer-like feedback -> consciousness
observer-like feedback -> objective collapse
self-reference -> new physics
adaptive memory -> stronger SoCT memory field
```

without independent evidence.

## Productive crossfeed rule

A Track-2 result may modify Track-1 experimental design only if it can be translated into:

1. an operational variable;
2. a causal intervention or ablation;
3. an ordinary-physics null model;
4. a measurable nuisance profile;
5. a preregisterable discriminator.

## Immediate joint research question

The highest-value bridge is:

> Holding record quantity and present state approximately fixed, does **causal reuse of a record** create any experimentally distinguishable consequence beyond passive storage?

For now this is a model-design question, not a claim that physics depends on reuse.

## Research sequence

```text
Track 1: continue SOC-HISTORY-01 platform/protocol work
Track 2: run O-1A passive-memory vs feedback simulation
Crossfeed: compare equal-record systems with different causal reuse
Then decide whether Gamma_use belongs only to observerhood metrics or deserves a separate Track-1 experimental hypothesis
```
