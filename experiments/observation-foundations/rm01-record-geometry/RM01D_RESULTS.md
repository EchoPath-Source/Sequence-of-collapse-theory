# RM-01D Results — Record-Only Higher-Structure Reconstruction

**Status:** completed first toy benchmark  
**Claim level:** methodology result only  
**Seeds:** 30 per family/mode  
**Reconstruction input:** persistent binary record supports only

## Question

Can higher-level geometric structure be recovered from persistent record relations
without supplying the reconstruction stage with the substrate family, coordinates,
edge list, bottleneck labels, shortcut labels, or target dimension?

RM-01C established that local propagation dynamics can generate record supports
whose Jaccard relations recover effective pairwise distance. RM-01D asks whether
the same record relations contain more than a scalar distance ordering.

The tested chain is:

```text
local relational dynamics
-> propagated influence
-> persistent records
-> record-support distance
-> family-agnostic relational reconstruction
-> neighborhoods / edges / bottlenecks / shortcuts / growth dimension
```

This does **not** derive physical spacetime. The generator still receives a
substrate graph and local edge properties.

## Reconstruction rule

For every event/source, downstream persistent record fragments define a binary
support vector `R_i`.

The reconstruction stage computes only

```math
d_J(i,j) = 1 - |R_i cap R_j| / |R_i cup R_j|.
```

A family-agnostic graph is then built by connecting each node to its four nearest
neighbors under `d_J`, symmetrizing the result, and reconnecting any rare
components using the smallest remaining record distance.

No family-specific reconstruction tuning is used.

## Gate A — neighborhood and direct-edge recovery

Across the six heterogeneous structure families

```text
cycle
torus
irregular
bottleneck
shortcut
variable_speed
```

the 30-seed aggregate is:

| Mode | 4-NN recovery | Edge AP | Edge ROC AUC |
|---|---:|---:|---:|
| local | 0.732 | 0.763 | 0.978 |
| scrambled | 0.080 | 0.080 | 0.506 |
| global | 0.078 | 0.081 | 0.505 |

Per-family local results:

| Family | 4-NN recovery | Edge AP | Edge ROC AUC |
|---|---:|---:|---:|
| cycle | 0.931 | 0.828 | 0.992 |
| torus | 0.672 | 0.703 | 0.975 |
| irregular | 0.748 | 0.865 | 0.983 |
| bottleneck | 0.661 | 0.645 | 0.968 |
| shortcut | 0.645 | 0.683 | 0.969 |
| variable speed | 0.734 | 0.856 | 0.981 |

### Interpretation

The result is substantially stronger than pairwise Spearman correlation alone.
Record-support distance ranks actual local adjacency well across all six families,
while locality-destroying controls fall to chance-level ROC AUC.

This supports the narrow toy-model statement:

```text
persistent records generated by local dynamics
retain recoverable neighborhood / adjacency information.
```

It does not imply that physical spatial adjacency is universally definable this
way.

## Gate B — bottleneck recovery

The bottleneck family contains two 5x5 regions connected by one slow bridge.

The reconstruction is not given the two-region labels.

A Fiedler-vector bipartition of the record-only inferred graph gives:

```text
local      adjusted Rand index = 1.000
scrambled  adjusted Rand index = 0.004
global     adjusted Rand index = -0.009
```

Across all 30 local seeds, the planted two-region partition is recovered exactly.

### Interpretation

Persistent record relations carry enough higher-order structure to expose the
large-scale bottleneck, not merely pairwise closeness.

This remains a planted synthetic benchmark. More irregular multi-community and
soft-bottleneck adversaries are still required.

## Gate C — nonlocal shortcut recovery

The shortcut family begins with a periodic 2-D torus and adds four low-cost edges
between pairs that are extremely distant under the background geometry.

For evaluation only, shortcut pairs are compared with the 20% most
background-distant node pairs.

The score is the percentile of background-far pairs whose record distance is
larger than the shortcut pair's record distance.

```text
local      mean shortcut closeness percentile = 0.996
scrambled  mean shortcut closeness percentile = 0.540
global     mean shortcut closeness percentile = 0.509
```

### Interpretation

The record relation follows the effective propagation structure rather than
merely preserving the original background embedding.

This extends the RM-01B/C observation that record geometry tracks effective
causal/path structure when real low-cost shortcuts are introduced.

## Gate D — equal-size dimension ordering

A naive cross-family dimension comparison is confounded by node count, graph
degree, and record density.

RM-01D therefore adds a separate equal-size suite:

```text
64-node cycle
8x8 periodic 2-D torus = 64 nodes
4x4x4 periodic 3-D torus = 64 nodes
```

For this suite every source has **exactly the same record cardinality**:
approximately 10% of all fragments are active.

- local mode samples fixed-cardinality supports from local-propagation exposure;
- scrambled mode preserves each exposure-weight multiset but permutes fragment
  identity;
- global mode samples the same fixed cardinality uniformly.

Thus all three geometry families and all modes have the same node count and
record density.

The dimension statistic is a deliberately simple local ball-growth exponent
computed on the record-only inferred graph using radii 1 and 2.

Results:

| Family | True finite-graph growth exponent | Local inferred | Scrambled inferred | Global inferred |
|---|---:|---:|---:|---:|
| cycle | 1.000 | 0.985 | 2.211 | 2.201 |
| 2-D torus | 1.585 | 1.686 | 2.203 | 2.201 |
| 3-D torus | 1.807 | 2.092 | 2.220 | 2.201 |

Mean absolute error:

```text
local      0.133
scrambled  0.747
global     0.737
```

Most importantly, the ordering test

```text
d_cycle < d_2D < d_3D
```

succeeds in:

```text
local      30 / 30 seeds = 1.000
scrambled   6 / 30 seeds = 0.200
global      0 / 30 seeds = 0.000
```

### Interpretation

The record-only reconstruction distinguishes the ordered local growth structure
of equal-size 1-D, 2-D, and 3-D periodic substrates after record density is
explicitly matched.

The numerical exponents are **not** accepted as unbiased estimates of continuum
dimension. The 3-D case is overestimated by the fixed `k=4` reconstruction, and
the tiny periodic lattices have strong finite-size effects.

The accepted result is therefore only:

```text
record structure contains recoverable information about relative local
growth/dimensional organization.
```

not:

```text
Jaccard records derive the dimensionality of physical spacetime.
```

## Predeclared-style gates and outcome

The implementation uses the following practical first-pass gates:

```text
mean local edge ROC AUC > 0.75
and > controls by 0.10                    PASS: 0.978 vs ~0.505

bottleneck ARI > 0.50                     PASS: 1.000

shortcut closeness percentile > 0.75      PASS: 0.996

equal-size dimension order success > 0.80 PASS: 1.000

local dimension MAE < both controls        PASS: 0.133 vs 0.747 / 0.737
```

All first-pass gates pass.

## Important negative / limiting results

1. **Dimension is not yet a derived observable.**  
   The inferred growth exponent depends on the graph-construction
   hyperparameter (`k=4`) and finite-size regime.

2. **Curvature-like diagnostics are not yet accepted.**  
   Simple graph-curvature surrogates depend strongly on inferred degree, so a
   fixed-k graph would partially hard-code the quantity being measured.
   Curvature should wait for an adaptive, record-only connectivity estimator.

3. **The substrate still exists before the records.**  
   RM-01D reconstructs structure implicit in local relational dynamics. It does
   not show that a geometric substrate can emerge without any supplied
   relational network.

4. **The generator and evaluator know the family; the reconstructor does not.**  
   Family labels are required to create controlled synthetic worlds and score
   recovery, but they are never passed to the reconstruction function.

5. **No SoCT-specific memory field is present.**  
   These records are ordinary synthetic persistent records generated by local
   stochastic dynamics.

## Surviving conclusion

RM-01 through RM-01D now support the following toy-model chain:

```text
local relational interaction
-> propagation
-> persistent record supports
-> overlap relations
-> effective distance
-> local adjacency
-> bottleneck / shortcut structure
-> relative growth-dimensional organization
```

This is stronger than the original RM-01 claim because several qualitatively
different geometric properties can be recovered from the same record
representation.

But the correct claim boundary remains:

> Persistent record relations can encode enough information to reconstruct
> multiple aspects of an underlying effective relational geometry in controlled
> toy systems.

They do not yet establish that spacetime itself is produced by observation,
records, collapse, or SoCT memory.

## Next gate — RM-01E

The strongest next test should remove the most important remaining assumption.

Instead of starting from a graph chosen to represent a familiar geometry:

```text
known substrate graph
-> local dynamics
-> records
-> recover geometry
```

generate a **pre-geometric relational network** from local rules alone:

```text
relation-update rules
-> evolving interaction network
-> propagation
-> persistent records
-> record-only reconstruction
-> competing compressed descriptions
```

Then compare candidate descriptions without telling the analysis that a
low-dimensional geometry should exist:

```text
1-D / 2-D / 3-D geometric embedding
hyperbolic embedding
tree / ultrametric
community/block model
small-world network
generic high-dimensional latent model
```

The meaningful RM-01E question is:

> Does a low-dimensional geometric description become the best compressed
> explanation of persistent record relations in any nontrivial regime, and does
> that regime arise without hard-coding the target geometry?

A negative result would be equally informative.
